# Ксения Гасникова — личная страничка

Светлая адаптивная страничка о танцах и акробатике. Фотогалерея с просмотром снимков и семь видео с управлением воспроизведением.

## Файлы

- `index.html` — разметка, стили и JavaScript.
- `assets/` — фотографии WebP, видео MP4 и обложки.

## Локальный запуск

Откройте `index.html` в браузере или поместите файлы в публичную папку локального веб-сервера. Сборка, PHP и база данных не нужны.

Tailwind CSS, Font Awesome и шрифты загружаются через CDN, поэтому для полного оформления нужен доступ к интернету. Фотографии и видео входят в репозиторий.

## Изменения

Тексты, оформление и ссылка Instagram редактируются в `index.html`. Для сохранения фотографий и видео не меняйте относительный путь `assets/` без обновления ссылок в HTML.

Личные фотографии и видео размещены владельцем сайта; открытый репозиторий не означает разрешения на их повторное использование.
